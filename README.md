# Overview
An item "drop" simulator for items in Counter-Strike 2. The tool lets you choose between one of the collections of items saved in the folder and simulates item drops from that collection, accurate down to the probabilities of each rarity type, and qualities of the items with respect to the game. Also allows for the in-game generation of the "received" item with a generation code that can be used in various community-made game servers for viewing items.

In its current state, a lot of the details are hard-coded, with just a few item collections to choose from (my favourites). If I return to this, I will update it to feature all item collections.
